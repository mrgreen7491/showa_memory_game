昭和の思い出・記憶力ゲーム v2（試作版）

■ フォルダー構成
showa-memory-game/
  index.html
  style.css
  script.js
  images/  ← 既存の30枚をそのまま使用

このZIPにはゲーム本体のファイルだけが入っています。
imagesフォルダーは含めていません。既存のimagesフォルダーを残してください。

■ 今回のゲームの流れ
1. 5枚のイラストを同時に15秒間表示します。
2. 5枚を隠し、「さっき見た5つの絵の中にあったものと同じ絵はどれでしょう？」と質問します。
3. かんたんは2択、少しむずかしいは3択、もっとむずかしいは4択です。
4. 正解画面では上段に最初の5枚、下段に選択肢すべてを表示し、上下段それぞれの正解イラストを点滅させます。
5. 不正解なら「残念でした。もう一度挑戦！」と表示し、同じ5枚を15秒間もう一度表示します。
6. 各難易度10問です。

■ 起動
3つのファイル（index.html / style.css / script.js）を
showa-memory-gameフォルダー直下にコピーし、index.htmlをEdgeまたはChromeで開きます。
ノートPCをHDMIで大型テレビにつなぎ、操作はスタッフが行ってください。

ネット接続・APIキーは不要です。
